# Ethics Materials

This directory contains materials prepared for ethical review and evaluation planning.

## Contents

- `materials/ETHICS_COMMITTEE_REQUEST_DRAFT.md`
- `materials/RESEARCH_EVALUATION_DRAFT.md`
- `materials/student_materials/`
- `materials/psychologist_materials/`
- `materials/submission-package/`

These documents focus on participant instructions, consent language, questionnaire drafts and interview/evaluation material. They are supporting research artefacts, not runtime application code.

Generated archives are not committed as source of truth. If a packaged submission is needed, create it from the text files in this directory.

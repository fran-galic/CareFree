# Research Materials

This directory contains material used to describe, evaluate and audit CareFree as a research-oriented prototype.

## Contents

- `audits/`: repository and targeted audits used to map implemented functionality, risks and evidence in the codebase.
- `figures/`: TikZ diagram sources for system overview, user flows, data model and Julija assistant behavior.
- `archive/progi-carefree-bundle/`: early project notes, prompt drafts and evaluation-planning material.

The audit documents are historical snapshots. Some file paths and findings may refer to the repository state before the documentation cleanup and should be read with their audit date in mind.

## Recommended Use

Use the research material to support:

- project reports
- methodology descriptions
- ethical review preparation
- architecture diagrams
- CV or portfolio descriptions of the applied AI/NLP component

Do not use archived prompt drafts as the source of truth for current assistant behavior. The current implementation lives in `backend/assistant/`.

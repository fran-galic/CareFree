# Demo Accounts

Demo accounts are generated by `scripts/seed_demo_caretakers.sh` and the Django management command `seed_demo_caretakers`.

## Generation

```bash
DEMO_CARETAKER_PASSWORD=<demo-psychologist-password> \
DEMO_STUDENT_PASSWORD=<demo-student-password> \
bash scripts/seed_demo_caretakers.sh
```

The script generates emails with predictable local-demo patterns, for example:

```text
ime.prezime.XX@demo.carefree.local
```

Demo student emails use the `carefree.local` domain.

## Credentials

Passwords are runtime demo credentials and should not be committed. Use the local generated snapshot after seeding:

```text
generated/LOCAL_DEMO_CREDENTIALS.md
```

That file is ignored by Git. If credentials need to be shared for a private demo, share them out of band.

## Stability

Demo account names remain stable as long as these inputs stay stable:

- profile image set in `demo_profiles/`
- seed ordering
- seed command defaults
- explicit password options passed to the script

If demo profile images or seed logic change, generated account names can change too.
